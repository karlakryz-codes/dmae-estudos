# DMAE Estudos

Aplicação web de estudos voltada para o concurso do DMAE Uberlândia 2026.

## Objetivo
Transformar as apostilas em um ambiente de estudos organizado, responsivo e fácil de usar.

## Funcionalidades
- 📚 Apostilas organizadas por capítulos
- 🔎 Busca
- 🌙 Modo escuro
- 🔤 Ajuste do tamanho da fonte
- ✅ Marcar capítulos concluídos
- 📈 Progresso de estudos
- ▶️ Continuar de onde parou
- 📝 Exercícios com correção automática
- 👤 Login individual
- ☁️ Sincronização do progresso

## Matérias
- Língua Portuguesa
- Matemática e Raciocínio Lógico
- Conhecimentos Específicos

## Tecnologias
- HTML
- CSS
- JavaScript
- GitHub Pages
- Firebase (próxima etapa)

🚧 Em desenvolvimento.
